# 채팅 시스템 가이드라인

## 개요
LLM과 아이 사용자 간의 교육용 상황극 채팅 시스템 (각 카테고리 20레벨)

## 시스템 구조

### 1. 채팅 세션 관리
- 각 아이별로 독립적인 채팅 세션 유지
- 카테고리별 학습 진행 상황 추적 (레벨 1-20)

### 2. 상황극 생성 로직
- 아이의 현재 레벨에 맞는 상황극 생성
- 8개 카테고리: 질서, 예절, 자조, 청결, 감정조절, 존중, 절약, 식습관
- 각 카테고리별 20개 레벨의 주제 (edu-lifestyle-korea.xlsx 기반)

### 3. 평가 및 레벨업 시스템
- 아이의 답변을 분석하여 적절성 평가
- 일정 기준 달성 시 해당 카테고리 레벨 증가
- 긍정적 피드백과 칭찬 제공

### 4. API 엔드포인트
- `/api/v1/chat/start/` - 채팅 세션 시작
- `/api/v1/chat/message/` - 메시지 전송
- `/api/v1/chat/history/` - 채팅 기록 조회

## 구현 요구사항
- LangChain 프레임워크 활용
- OpenAI GPT 모델 사용
- 아이 친화적인 언어 사용
- 안전한 콘텐츠 필터링
