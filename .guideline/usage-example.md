# 채팅 시스템 사용 예시

## 1. 채팅 세션 시작 예시

### 요청
```json
POST /api/v1/chat/start/
{
    "child_id": 1,
    "category": "order"
}
```

{

## 2. 아이 답변 및 피드백 예시

### 2-1. 일반적인 답변 (레벨업 아님)

#### 요청
```json
POST /api/v1/chat/message/
{
    "session_id": 1,
    "content": "장난감을 상자에 넣을래요!"
}
```

#### 응답
```json
{
    "feedback": "좋은 생각이야! 장난감을 상자에 넣으면 방이 깔끔해지겠네. 잘했어! 👏",
    "score": 4,
    "level_up": "",
    "next_question": "지민아, 이번에는 다른 상황이야. 친구가 지민이의 크레용을 빌려달라고 했는데, 지민이가 아직 그림을 다 그리지 못했어. 지민이라면 어떻게 할까?",
    "session_ended": false
}
```

### 2-2. 레벨업 달성 답변

#### 요청
```json
POST /api/v1/chat/message/
{

    "content": "장난감을 상자에 넣고 책상도 깨끗하게 정리하고, 바닥도 쓸어서 완전히 깨끗하게 만들래요!"

```

## 3. 메시지 흐름 예시

### 전체 대화 흐름
```
1. 세션 시작 → 첫 번째 상황극 질문
2. 아이 답변 → 피드백 + 다음 질문
3. 아이 답변 → 피드백 + 다음 질문
4. ... (반복)
5. 아이 답변 → 피드백 + 레벨업 메시지 → 세션 종료
```

## 4. 카테고리별 상황극 예시

### 예절 (manners) - 레벨 1
```
"서윤아, 안녕! 오늘 아침에 할머니를 만났어. 할머니가 서윤이에게 손을 흔들며 웃고 계셔. 서윤이라면 할머니께 어떻게 인사할까?"
```

### 감정조절 (calm) - 레벨 2
```
"지민아, 친구가 지민이의 크레용을 빌려달라고 했는데, 지민이가 아직 그림을 다 그리지 못했어. 지민이 마음이 조금 답답하고 화가 날 것 같아. 이럴 때 지민이는 어떻게 할까?"
```

### 절약 (saving) - 레벨 3
```
"서윤아, 마트에서 엄마와 함께 장을 보고 있어. 서윤이가 좋아하는 과자가 두 종류 있는데, 하나는 비싸고 하나는 저렴해. 둘 다 맛있어 보여. 서윤이라면 어떤 선택을 할까?"
```

## 5. 레벨업 조건

### 평가 기준
- 1점: 부적절하거나 이해하지 못한 답변
- 2점: 기본적인 이해는 있으나 부족한 답변
- 3점: 보통 수준의 적절한 답변
- 4점: 좋은 답변, 상황을 잘 이해함
- 5점: 매우 훌륭한 답변, 창의적이고 사려깊음

### 레벨업 조건
- 최근 10개 답변의 평균 점수가 4.5 이상
- 최소 5개 이상의 답변 필요
- 레벨업 시 세션 자동 종료

## 6. API 응답 필드 설명

### /chat/message/ 응답 필드
- `feedback`: 아이 답변에 대한 피드백 메시지
- `score`: 답변 평가 점수 (1-5점)
- `level_up`: 레벨업 시 축하 메시지 (없으면 빈 문자열)
- `next_question`: 다음 상황극 질문 (레벨업 시 빈 문자열)
- `session_ended`: 세션 종료 여부 (레벨업 시 true)
