# 채팅 시스템 구현 가이드

## 시스템 개요
LLM과 아이 사용자 간의 교육용 상황극 채팅 시스템으로, 8개 카테고리별 레벨에 맞는 학습을 제공합니다.

## 주요 기능

### 1. 상황극 생성
- 아이의 현재 레벨과 카테고리에 맞는 교육용 상황극 자동 생성
- LangChain과 OpenAI GPT를 활용한 자연스러운 대화
- 아이 친화적이고 교육적인 콘텐츠 제공

### 2. 실시간 평가 시스템
- 아이의 답변을 1-5점으로 자동 평가
- 즉시 피드백과 칭찬 제공
- 학습 진행도 추적

### 3. 레벨업 시스템
- 최근 10개 답변의 평균 점수가 4.5점 이상일 때 레벨업
- 레벨업 시 세션 자동 종료
- 카테고리별 독립적인 레벨 관리
- 성취감을 주는 축하 메시지

## API 엔드포인트

### 1. 채팅 세션 시작
```
POST /api/v1/chat/start/
{
    "child_id": 1,
    "category": "order"
}
```

### 2. 메시지 전송
```
POST /api/v1/chat/message/
{
    "session_id": 1,
    "content": "아이의 답변"
}
```

### 3. 채팅 기록 조회
```
GET /api/v1/chat/history/{child_id}/
```

## 데이터베이스 모델

### ChatSession
- child: 아이 사용자 참조
- category: 학습 카테고리
- current_level: 현재 레벨
- scenario: 생성된 상황극
- is_active: 활성 상태
- progress_score: 진행도 점수

### ChatMessage
- session: 채팅 세션 참조
- sender: 발신자 (llm/child)
- content: 메시지 내용
- evaluation_score: 평가 점수

## 환경 설정
- OPENAI_API_KEY: OpenAI API 키 설정 필요
